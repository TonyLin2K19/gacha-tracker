# 版本紀錄

## 0.4.0

- 新增「大保底觸發次數」總覽欄位與 CSV 匯出；歷史起始資料可補填已發生的次數，後續到達指定抽數且確認出 UP 時自動累加。贈送抽、提前 UP、順序或 UP 狀態未知的紀錄不推算觸發次數；編輯／刪除後重新計算，跨池期總次數保留。
- 快速十抽及詳細紀錄新增「贈送」標記，抽取結果與統計保留，但不增加或重設一般／大保底、必 UP 狀態及鋼嵐套裝保障進度；歷史紀錄顯示贈送標記，可編輯修正。
- 卡池可獨立設定大保底必 UP 抽數（0 關閉）：歪的最高稀有度不重設，普通抽取每次出 UP 後歸零。總覽顯示進度與「下抽必出 UP」；大保底到期時下抽最高稀有度機率為 100%。
- 大保底換池繼承獨立於一般保底；不繼承時新池歸零、舊池恢復原進度。換池紀錄保存當時設定，之後修改不回溯改變已保存的繼承選擇。
- 舊歷史無法確定上次 UP 位置時顯示未知，可在歷史起始資料補入大保底起始墊抽。
- 左下角版本號改由 package.json 自動讀取，修正 0.3.2 仍顯示寫死的 v0.3.1 問題。

## 0.3.2

- 修正總覽混合完整與部分稀有度卡池時的配色錯位：同名欄位依同遊戲包含該名稱的最完整稀有度設定統一配色，避免海運池缺少 SSR 時將其 0 值誤顯示為彩色，並維持 SSR／SR／R 為金／紫／綠。
- 新增完整與部分稀有度混合顯示的回歸測試。

## 0.3.1

- 修正一般 HTTP 環境新增卡池／鋼嵐套裝池失敗：池期 ID 改由後端產生，不依賴瀏覽器 crypto.randomUUID。
- 欄位顯示設定依遊戲保存，沿用舊版偏好作為初始設定。
- 深色模式宣告原生控制項 color-scheme，並指定下拉選項背景與文字色，改善展開白底問題。
- 31 項測試與正式建置通過；以區網 HTTP 實測兩種新增入口及欄位重新整理保存。

## 0.3.0

- App 名稱改為「星願旅記 / GACHA JOURNEY」。
- 所有帳號卡池可建立或切換 UP 池期，新增「換池時繼承保底」設定；切換紀錄保存當時的繼承選擇。
- 不繼承時，新池從零開始，切回既有池則恢復該池最後的墊抽與必 UP 狀態；鋼嵐機甲維持共用保障標記與各池獨立階段。
- 卡池列表可編輯池期名稱，查看各期抽取紀錄、稀有度數量、出貨率與平均抽數；跨期總累積保留。
- 既有未命名池期預設為「卡池一」，已有池名保留；更名不影響紀錄、保底或池期識別。
- 四級稀有度依序彩色漸層、金、紫、綠；三級依序金、紫、綠。
- 可刪除整個遊戲與其所有卡池／紀錄。刪除遊戲或帳號卡池均須輸入 `DELETE`，前後端都驗證。
- 刪除前備份完整 SQLite DB 與 JSON，備份失敗中止刪除。備份位於 `/data/backups`，JSON 可從介面還原。

### 更新

Unraid 使用 `ghcr.io/tonylin2k19/gacha-tracker:latest` 檢查並套用更新，或使用固定 `:0.3.0`。
沿用現有 `/data` 掛載；舊版 JSON 仍可匯入，不必重新建池。
舊資料預設繼承保底。限定池請在「編輯帳號卡池」關閉繼承，再新增下一期。
先前已混在歷史基底中的抽取無法自動拆回各期；仍歸屬原始池期，可在卡池列表更名。
